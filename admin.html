게스트 가이드

이 버튼은 챗봇 ON/OFF와 변경 사유만 저장합니다. OFF 후 저장하면 고객 화면의 AI 입력창·챗봇 버튼·대화창이 숨겨지고 API 요청도 차단됩니다. 이미 열린 고객 화면은 새로고침해야 반영됩니다. 변경 사유는 관리자에게만 표시됩니다.

숙소 정보 수정 → 미리보기 → 게스트에게 게시
아래 입력란의 수정 내용과 호출 한도는 하단 ‘게스트에게 게시’를 눌러야 적용됩니다. ‘초안 저장’은 작업 보관용입니다. 각 입력란의 ‘현재 고객 페이지 열기’는 이미 게시된 화면을 엽니다.
